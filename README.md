# anubisproductions.github.io

The Anubis Productions website: the studio page for Hashi, its privacy policy, and
`app-ads.txt` for AdMob verification. Plain HTML and one stylesheet, no build step and
no third-party requests — the display font is served from this repository.

- `index.html` — studio page
- `privacy/hashi.html` — the policy the Play listing links to
- `app-ads.txt` — placeholder until AdMob issues the publisher line
- `assets/` — logo, game icon, Cinzel (OFL)

Served by GitHub Pages from `main`. Editing a file here publishes it within a minute.
